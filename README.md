# Simple AI Agent Communication Simulation

This Python script simulates a basic multi-agent system where agents communicate and share information to achieve a common goal. It demonstrates how agents can perceive their environment, make simple decisions, and send messages to each other without direct human intervention.

## Language

`python`

## How to Run

Save the code as `agent_simulation.py` and run it from your terminal using: `python agent_simulation.py`
